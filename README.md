# Lebohang Woodworking & Upholstery (Pty) Ltd Website

A modern multi-section business website built using pure HTML, CSS, and JavaScript for Lebohang Woodworking & Upholstery (Pty) Ltd.

The website showcases:
- Woodworking services
- Upholstery services
- Construction & contracting services
- Company profile
- Project gallery
- Quote request system via WhatsApp

---

## Features

### Modern UI Design
- Premium navy & gold branding
- Responsive layout
- Smooth animations
- Glassmorphism navigation
- Mobile-friendly interface

### Multi-Page SPA (Single Page Application)
The website uses dynamic page switching without reloading the browser.

Pages included:
- Home
- Services
- About
- Contact
- Quote Request

### Service Showcase
Displays:
- Woodworking projects
- Custom furniture
- Renovations
- Steel fabrication
- Roofing
- Upholstery work

### WhatsApp Integration
Users can:
- Request quotes directly
- Contact business instantly
- Send pre-filled enquiry forms

### Responsive Design
Optimized for:
- Desktop
- Tablet
- Mobile devices

---

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

No frameworks or external libraries are required.
